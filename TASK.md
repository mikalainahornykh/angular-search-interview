# Задача: поиск пользователей

Есть страница со списком пользователей и поиском. Поиск уже написан и на первый
взгляд работает, но пользователи жалуются. Нужно довести его до продакшен-качества.

Работаем в `src/app/users-search/users-search.ts`, при желании можно создавать новые файлы.

**Ограничения:** Angular signals + RxJS. `resource` / `rxResource` / `httpResource` не используем.

## Этапы

### 1. Лишние запросы
- Сейчас запрос уходит на каждое нажатие клавиши. Так быть не должно.
- Не нужно отправлять повторный запрос, если строка поиска по сути не изменилась.

### 2. Актуальные результаты
- На экране всегда результаты по **последней** введённой строке, даже если
  ответы сервера приходят в другом порядке.

### 3. Состояния
- Загрузка: пользователь видит, что идёт поиск.
- Пустой результат: сообщение вида «Nothing found».
- Ошибка: понятное сообщение и кнопка «Retry».

## Что есть в проекте

- `UsersApi.search(query): Observable<User[]>` — готовый клиент API.
- Бэкенд фейковый ([Mock Service Worker](https://mswjs.io)): запросы настоящие и видны в DevTools → Network,
  отвечают со случайной задержкой и иногда падают с ошибкой 500. Запрос со словом `error` падает всегда.
  Удобнее открыть превью в отдельной вкладке (кнопка в правом верхнем углу превью) и пользоваться DevTools там.
- В `src/styles.css` есть готовые классы: `.state`, `.state.error`, `.spinner`, `.btn`,
  `.results.is-loading`. Вёрстку делать не нужно.

иногда перестаёт открывать `.ts`-файлы с кириллицей.
